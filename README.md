# -guia-boas-praticas-inovaweb
 Manual de boas práticas digitais desenvolvido para clientes da agência.

 Autor: Luiz Eduardo de Jesus Santos
 
 Resumo: Este guia apresenta os padrões técnicos, processos de desenvolvimento e
 diretrizes de comunicação da InovaWeb. O material foi estruturado para alinhar a equipe
 otimizar o fluxo de trabalho e garantir a qualidade e a segurança das entregas digitais da empresa.
